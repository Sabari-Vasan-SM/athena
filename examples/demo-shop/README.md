# demo-shop

A small shop API (Express 5, Prisma, PostgreSQL) used as an example project for
[Athena](../../README.md). The `.athena/` folder and `AGENTS.md` were generated by
Athena; everything else is ordinary application code.

```bash
cp .env.example .env   # then fill in DATABASE_URL and API_TOKEN
npm install
npm run db:migrate
npm run dev
```

Endpoints: `GET /health`, `GET /products`, `GET /products/:id`, `POST /orders`
and `GET /orders/:id` (the order endpoints need `Authorization: Bearer $API_TOKEN`).
